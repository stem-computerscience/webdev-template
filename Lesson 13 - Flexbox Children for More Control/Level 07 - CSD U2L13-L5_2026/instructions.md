# Align-self

The `align-self` property aligns an item in a flex container. It is important to remember, that this property _overrides_ the container's `align-items` value.

The second item in the image below has an `align-self` value of `flex-end`.

<img src="https://images.code.org/878fc7cab1febedb425fcc9b6a548576-image-1707153107070.png" style="width:600px;">

# Do This

**In the HTML file:**
1. Give the second child item inside the "flex-align" parent a class attribute of "align"

**In the CSS file:**
1. Add a rule in the CSS file for the second child item using its class attribute as the selector.
2. Give the item the `align-self` property.
3. Try out the different values: 
   - `flex-end`
   - `flex-start`
   - `center`
   - `stretch`
   - `baseline` _(you will only see a visual difference with this value if the items have different heights)_
