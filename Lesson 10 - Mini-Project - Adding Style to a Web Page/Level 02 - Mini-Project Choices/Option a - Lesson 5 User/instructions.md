# Add CSS File

The HTML code you wrote for your user in the previous mini-project has been carried over to this level so that you can style the web page according to your user's requests in your project guide. 

In order to start styling the web page for our user, we need to add the CSS file.

# Do This
1) Add the CSS file to the project.
2) Rename your CSS file to "style.css"
3) Add the link for your CSS file in the `head` tag.
