# Flex-flow

`flex-flow` is shorthand for the `flex-direction` and `flex-wrap` properties, which together define the flex container's set up. The default value is `flex-flow: row nowrap;` which establishes the direction as "row" and the wrap as "no wrap". See if you can use this new shorthand property to match the image on the right. 

The first container has been styled for you with `flex-flow: column wrap;`. 

_Don't forget that when you use column for the direction, the horizontal and vertical alignment properties switch!_

# Do This

1. Give each container the `flex-flow` property and appropriate values according to the image.
2. Define the horizontal alignment for each container to match the image to the right.
3. Define the vertical alignment for each container to match the image to the right.
