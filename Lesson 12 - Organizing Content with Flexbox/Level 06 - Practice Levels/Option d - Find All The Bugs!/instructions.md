Trinity was making this webpage to blog about her love of Super Mario but she has run into some problems. She had the page looking like the image to the right but then she wasn't paying attention and changed some stuff and can't figure out where the bugs are. Can you help her?

# Do This

1. Look through both the HTML file and the CSS file to see if you can find and fix all 4 bugs to get Trinity's page to look like the image to the right.
