# Your Favorite Movies

Now that you have learned how to create HTML headings, lists, and code special characters, you can put your skills to the test!

# Do This
1) Create a web page about your favorite movies!
	- For example, this web page could include information about your favorite genre of movies and then a list of your top 3 favorites!
    - You could even do favorite movies and use the horizontal rule tag to separate the descriptions of each one!

You may not be able to create the "perfect" web page just yet, but you can develop a prototype that shows your general idea!

## Teacher Notes

While this level does contain an exemplar, because of how open-ended the directions are, we encourage you to consider this as a focused free-play level.
