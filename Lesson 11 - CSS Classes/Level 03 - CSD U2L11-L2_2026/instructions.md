# Using Classes

This waterfall page uses classes to make the images at the top of the page a different style from the images in the main part of the page.

# Do This

1) Find the CSS rule set in the `style.css` file that makes the images at the top smaller than the ones on the main part of the page.
* Add a new rule to one of the classes, and check to see that it only affects the images in that class.
