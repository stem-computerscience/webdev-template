# Individual Ids

You can also use the `id` attribute to single out just one element for a rule-set.  

# Do This

1) Look at the image element with the `<img id="notes" src="Raseone-Music.png" alt="music notes">` tag, and notice the `id` attribute.
* In `style.css`, look at the rule-set with the `#notes` selector.  Notice how it uses a `#` instead of a period.
* Add a new image into the page from the available files, and give it its own style.
