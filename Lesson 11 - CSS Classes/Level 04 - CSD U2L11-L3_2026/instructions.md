# CSD U2L11-L3_2026

# The Four Ghosts

This page describes the four ghosts from Pac Man and Mrs. Pac man, but only one of them is styled with a special class.

# Do This

1) Look through the code to see how the "blinky" class works.
2) Add a new class attribute in the `index.html` file for each of the other three ghosts.
3) Add a class rule-set in the `style.css` file for each of the three ghosts.
4) Add properties to each rule set to style the ghost's image and paragraph differently.
