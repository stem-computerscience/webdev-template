# Do This

2) Use at least three CSS properties to style the special haiku.


<details><summary>What does the <strong>&lt;br&gt;</strong> tag do?</summary>

The &lt;br&gt; tag is used here to start a new line inside the same paragraph. In the code below, each poem is still treated like one big paragraph. However, the &lt;br&gt; tag puts each line of the haiku is on its own line. <em>You do not need to add any CSS or classes to the &lt;br&gt; tags.</em>
</details>
