# Basic Steps

Let's practice the all 3 steps we learned in the Skill Building levels: 
1. Establish flex layout.
2. Define the flow direction and if items should wrap.
3. Define how the items should be distributed horizontally across the container.

We will also define how the items should be distributed vertically. 

# Do This

For both `div` containers:
1. Establish flex layout.
2. Define which direction the images should be placed.
3. Define if items should wrap or not.
4. Define how the content should be spaced horizontally across the container.
5. Define how the items should be spaced vertially in the container.
