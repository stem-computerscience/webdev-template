# CSD U2L11-L4_2026

# Young Adult Novels

Let's continue practicing using classes with this article on different young adult novels.

# Do This

1) Give each heading and paragraph tag class attribute names.
   - *The first novel's heading and paragraph has already been done as an example.*
2) Go into the stylesheet and give each novel heading and paragraph a different style including:
   - Color
   - Font
   - Border style
   - Border color
   - Background color
3) Add any other stylings you think make the article look better!
