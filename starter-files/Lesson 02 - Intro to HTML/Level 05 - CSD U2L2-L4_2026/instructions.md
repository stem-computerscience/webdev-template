# Use Paragraph Tags

The `<p>` `</p>` tags or "paragraph" start and end tags are placed around text to indicate that it is part of a paragraph. Placing text between paragraph start and end tags lets the computer know that it should be treated differently, often just spacing it out from other text.

# Do This

1) Click in between the `<body>` and `</body>` tags - this is where you'll add your code
* Create two paragraphs that ask a question and answer it. This can be a trivia question, a riddle, or a joke.
	- For example: "What continent has the largest land mass?" - "Asia"
- Place the text you just wrote inside two separate paragraphs by surrounding each line with `<p>` and `</p>` tags
