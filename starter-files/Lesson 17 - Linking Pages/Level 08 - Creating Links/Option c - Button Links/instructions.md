# Button Links

*Learn how to style hyperlinks to make them look like buttons*

# Button Links

Take a look at the image below of the five hyperlinks that have been styled to look like buttons. Can you figure out what properties and values you will need to use to make the links look like this?

<img src="https://images.code.org/d50aa0a8bfa5620990273c394baadeb3-image-1677527856343.png" style="width:350px">

# Do This

1) Find the CSS rule for hyperlinks in your stylesheet.
2) Add the following properties to the hyperlink rule-set with values of your choice:
   * border-style
   * border-color
   * border-radius
   * padding
   * text-decoration
      * *Select "none" for this property*
3) Add the optional properties to the hyperlink rule-set with values of your choice to make the buttons more visually appealing:
   * background-color
   * color
