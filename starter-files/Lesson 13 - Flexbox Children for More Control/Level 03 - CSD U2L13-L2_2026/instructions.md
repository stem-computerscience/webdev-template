# Flex-grow

The `flex-grow` property specifies how much a flex item will grow relative to the rest of the flex items.

The last item stretches to fill the remaining space. Item 3 below has `flex-grow` set to `5` which means it will grow up to 5 times more than the other items or until the container is filled.

<img src="https://images.code.org/0fd52bfb0eaed029b17aea3763cb66b8-image-1707149814516.png" width="500px;">

# Do This

**In the HTML file:**
1. Give the third child item a class attribute of "grow"

**In the CSS file:**
1. Add a rule in the CSS file for the third child item using its class attribute as the selector.
2. Give the third child item a `flex-grow` property with a value of 5.
3. Resize the Preview Window to see the size change accordingly.
