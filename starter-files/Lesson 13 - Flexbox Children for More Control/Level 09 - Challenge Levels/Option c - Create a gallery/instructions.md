# Info Card Layout Challenge

When we start putting elements into containers within containers and using Flexbox properties and children properties, we unlock the ability to give our web pages some cool layouts! 

Let's see if we can turn the bottom half of this page into a nice, image and info gallery like the image on the right!

# Do This

::: details [**In the HTML file:**]
1. Find the "gallery" container.
2. Add a `div` container around each paragraph in the gallery with the class attribute "info"
3. Add a `div` container around each image in the gallery with the class attribute "image"
4. Add a `div` container around each of the image and paragraph groups with the class attribute "image-card"

**_The `div` tags for the first two groups of images and paragraphs have been done for you. Use them as examples for the remaining four groups of images and paragraphs._**
:::

<br>

::: details [**In the CSS file:**]
1. Establish Flex layout and "wrap" for the "gallery" container.
2. Set the content of the "image-card" to grow at a value of 1 so they all grow at the same rate.
3. Establish Flex layout for the "image-card" so that _its_ child elements can use Flex too
4. Set the "info" container content to align itself to the center.

:::

<br>

::: details [**EXTRA CHALLENGE**]
Can you figure out how to set the order of the "image-card" for the giant squid to be the first image in the gallery, just like the image above?

_Hint: You will probably have to give the "image-card" a different class attribute in order to set its order! 🤔 Hmmm ... but then how will it continue to have the same properties as the "image-card"?_ 🤔
:::
