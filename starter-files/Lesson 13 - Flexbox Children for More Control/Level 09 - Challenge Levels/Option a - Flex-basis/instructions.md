# Flex-basis

*Learn about another Flex child property that determines the size of your item!*

# Flex-basis

`flex-basis` is another child Flex property that is used to establish the size of your item. Think of it as the same thing as defining an element's `width`.

The default value for this property is `auto` which sets the **ideal size of the element based on its content**. We can also set a specific size for our elements by defining the value of `flex-basis`. 

# Do This

**In the CSS file:**
1. Add the `flex-basis` property to the first container and set value to `auto`
   - _This will set the "ideal size" of the element based on its content._
2. Add the `flex-basis` property to the second container and set value to `150px`
   - _This will explicitly set the size of the element to `150px`

**In the HTML file:**
1. Add some more text to **one** of the paragraphs in the **"basis-auto"** container. 
   * Notice how the element will expand as much as it can while still keeping the other two elements at their ideal size based on their content.
   * _This is the default for all Flex items._
2. Add some more text to **one** of the paragraphs in the **"basis-fixed"** container.
   * Notice how the element's width does not change since you set it to be 150px.
