# Debug Me!

Oh no! Mya was making a page on the Earth's Ecosystems but she can't quite get the images in the right place! Please help her debug the code so that her page matches the one in the image to the right!


# Do This

1. Can you find and fix the bugs for each of the image order and alignment layouts in the CSS file to make the page match the image to the right?
   - _Make sure you view the Preview Window in fullscreen to see if it matches!_

<br>

<img src="https://images.code.org/2e2aa789388abcb84fd701adb5023d9f-image-1707769633508.png" style="width:150px; float: left;">

_**Tip:** You might find it helpful to change the `width` of the images to a smaller size while you are debugging so that you can see more images in your Preview Window and see the immediate debugging effects without having to view fullscreen. Just remember to change the `width` back when you find and fix all the bugs!_
