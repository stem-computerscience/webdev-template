*Practice setting the `flex-grow` property based on if you want items to grow equally or not!*

# Grow Based on Container Content!

Let's do some more practice with the `flex-grow` property! It turns out, this property can do some cool stuff for our children elements!

For example, if we give all child elements a value of `0`, this means that the elements will grow based on the content inside it! So, if one element has more content, it will be larger than the others in the container. Pretty handy!

Now, if we want all of our child elements to take an equal portion of the parent container, then we can give all of our children a `flex-grow` value of `1`! 

Let's give this a try!

# Do This

**In the CSS file:**
1. Add the `flex-grow` property to the first container and set the child elements grow based on the content inside the container. _See above description to remember what that value should be._
2. Add the `flex-grow` property to the second container and set the child elements take an equal portion of the parent container. _See above description to remember what the value should be._

**In the HTML file:**
1. Add some more text to **one** of the paragraph in the **"grow0"** container to see the item sizes adjusting based on the content!
   * _This is the default for all Flex items._
