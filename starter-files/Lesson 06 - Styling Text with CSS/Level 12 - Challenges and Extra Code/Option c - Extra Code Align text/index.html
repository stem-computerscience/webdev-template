Build a Terrarium!

What's a terrarium?

A terrarium is usually a sealable glass container containing soil and plants, and can be opened for maintenance to access the plants inside.

From Wikipedia

How do they work?

The glass lets the light in, but it also keeps the water inside so there can be a water cycle. That way your plants get all the sun they need but never lose any water!

How can I make one?

Get a big glass jar, and put it on its side, then put your dirt and plants inside. Then make sure there's enough water and clse up the jar.
