Using RGB
Experiment with the RGB values in the CSS style sheet.

Do This
1) Find the CSS rule-set in the style sheet that gives the h1 tag its style. Change only the first 0 to 255.
2) Find the CSS rule-set in the style sheet that gives the p tag its style. Change only the second 0 to 255.
3) Find the CSS rule-set in the style sheet that gives the h3 tag its style. Change only the third 0 to 255.

    color: rgb( 255 , 0, 0);
