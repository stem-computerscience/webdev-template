*Use CSS to change the font family of the headings and paragraphs*

# Change Font Family

Change the font family of both the heading and the text. There are several font families including `cursive`, `fantasy`, `serif`, and `monospace`.

# Do this
1) Add a rule-set for one of the heading types to make it a different font family.
* Add a rule-set for the paragraphs to make them another font family.
