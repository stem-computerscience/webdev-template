*Choose this level to style Sofia's computer repair and technology services web page!*

# Add Style

Add rule sets to your CSS stylesheet to style your user's web page!

# Do This
1) Add style for each of the elements on your user's page:
   - the body
   - headings
   - paragraphs
   - lists
   - images
2) Refer to your project guide to make sure you are styling each of the elements according to your user's request. These include:
   - background color
   - font color
   - font family
   - font size
3) You also have the option to add the following style to enhance your user's page even more:
   - text alignment
   - text decoration
   - letter spacing
   - text shadow
   - image size
   - border style
   - border radius
   - border color
   - margin
   - float
