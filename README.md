# Unit 3 - Web Development

Mirrors all 21 lessons (Chapters 1-2) from Code.org's AI Discoveries 2026
course (`ai-discoveries-2026`).

Each lesson folder has a `lesson-plan.md` with the full lesson plan,
teaching guide, and resource links. Each level (and each lettered option
within a multi-option level) has its own folder with an `instructions.md`
containing that level's instructions, plus any starter files (HTML, CSS,
JS, and images) provided to students.

- **Chapter 1 - Creating Webpages**: Lessons 1-14
- **Chapter 2 - Multi-Page Websites**: Lessons 15-21
