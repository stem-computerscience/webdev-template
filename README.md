# Web Dev Template

Repo scaffold for Web Development** (Code.org),
organized by chapter, lesson, and level so each lesson/level has its own
working folder.

## Structure

- `chapter-1-creating-webpages/` - Lessons 1-14
- `chapter-2-multi-page-websites/` - Lessons 15-21

Each lesson folder contains one subfolder per level (`level-01-...`, `level-02-...`),
each with a starter `index.html` (and `style.css` where the lesson covers CSS).
Lessons with no numbered levels (7, 15, 16) contain a single `README.md` instead.
