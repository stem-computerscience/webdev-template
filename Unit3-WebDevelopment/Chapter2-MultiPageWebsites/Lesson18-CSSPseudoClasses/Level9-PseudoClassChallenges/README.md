# Level 9: Pseudo-class Challenges

**Lesson:** [Lesson 18 — CSS Pseudo-classes](../README.md)
**Type:** Challenge
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/18/levels/9

## Instructions

Enhance your pseudo-class skills!

- **a — Hidden Text:** Learn how to use the "hover" pseudo-class to hide and reveal text!
- **b — Image Emphasis:** Learn how to use the "hover" pseudo-class to bring a user's attention to an image!
- **c — Revealed Secret:** Learn another way to use the "hover" pseudo-class with a div tag to reveal text!
- **d — Responsive Page Elements:** Learn how to create responsive image cards!
