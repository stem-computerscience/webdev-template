# Level 6: Practice Levels

**Type:** Practice
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/2/levels/6

## Instructions

Try out what you've learned on one or more of the following activities:

- **a — Creating Paragraphs:** Revisit the first level from this lesson to write your name, favorite color, and favorite animal using paragraph tags.
- **b — Alternating Stories:** Work with your neighbor to tell a Fortunately / Unfortunately story using paragraph tags.
- **c — * Pyramid:** Use paragraph tags to create a sideways pyramid out of `*` symbols.
