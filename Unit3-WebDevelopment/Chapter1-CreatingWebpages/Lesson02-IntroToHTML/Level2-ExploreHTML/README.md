## Instructions

This is a web page written in HTML, the language of the web. You'll learn more about how it works, but first explore it by using the Inspector Tool.

### Do This
Click on the AI tutor icon. Once you turn on the AI Tutor tool, you can chat with an AI Chatbot to help learn about web development.

**With AI Tutor:** Copy parts of the HTML into the chatbox and determine:
- What code makes the text bigger and bolder?
- What code makes text appear as a list?
- What code makes the text appear on separate lines?
- What's a piece of code that doesn't appear to do anything on the screen?
