## Instructions

Here are some HTML tags that you may have seen in the past couple of lessons. You can use them to review the tags you might want for your web page.

- **a — Paragraphs:** Add paragraph tags to separate the paragraphs.
- **b — Debug: Paragraph Tag:** Find the bugs caused by incorrect paragraph tags.
- **c — Debug missing paragraph:** Use your debugging skills to figure out why the paragraph has disappeared.
- **d — Debug: Headings:** Fix the bugs caused by incorrect heading tags.
- **e — Add Larger Heading:** Add a large heading to the top of a web page.
- **f — Debug Ordered List:** Use your debugging skills to figure out why the list is not showing up correctly.
- **g — Line Break:** Separate the lines of the haiku using the `<br>` tag.
