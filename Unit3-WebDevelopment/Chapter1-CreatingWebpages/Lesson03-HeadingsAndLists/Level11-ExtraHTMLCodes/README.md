# Level 11: HTML Headings — Extra Codes & Free Play

**Lesson:** [Lesson 3 — Headings and Lists](../README.md)
**Type:** Challenge
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/3/levels/11

## Instructions

Here are some extra HTML codes to try out, and a Free Play area to use them in.

- **a — Line Break:** Learn how to make new lines without starting a new paragraph. You can use this code to add poems or lists to your page.
- **b — Horizontal Rule:** Learn the code for making a horizontal rule and practice using it.
- **c — Special Character "&":** Learn the code for the special character "&" and practice using it.
- **d — Your Favorite Books:** Try using the new code you have learned to create your own HTML page about your favorite books.
- **e — Your Favorite Movies:** Try using the new code you have learned to create your own HTML page about your favorite movies.
- **f — Your Favorite Games:** Try using the new code you have learned to create your own HTML page about your favorite games.
