# Level 4: Headings Quick Check

**Lesson:** [Lesson 3 — Headings and Lists](../README.md)
**Type:** Quick Check (Assessment)
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/3/levels/4

## Instructions

Look at the code below and predict how the headings will be displayed. Choose from one of the options on the right.

```html
<h3> Eggs </h3>
<h1> Bacon </h1>
<h6> Waffles </h6>
```

Answer choices A, B, C, and D each show a different rendered arrangement of the three lines of text at different sizes (shown as images on the page, not reproducible as text here).

**Correct answer:** B.
