# Level 5: Using RGB

**Lesson:** [Lesson 6 — Styling Text with CSS](../README.md)
**Type:** Skill Building
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/6/levels/5

## Instructions

Experiment with the RGB values in the CSS style sheet.

### Do This
- Find the CSS rule-set in the style sheet that gives the h1 tag its style. Change only the first 0 to 255.
- Find the CSS rule-set in the style sheet that gives the p tag its style. Change only the second 0 to 255.
- Find the CSS rule-set in the style sheet that gives the h3 tag its style. Change only the third 0 to 255.

*(Show Me How / Help & Tips are available in this level.)*

Discuss the results with your neighbor:
- What did each of those changes do to the color of your HTML components?
- What do you think that means for each of those values in the RGB code?
