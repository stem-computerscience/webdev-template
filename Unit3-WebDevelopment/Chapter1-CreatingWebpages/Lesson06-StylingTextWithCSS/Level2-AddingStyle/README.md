# Level 2: Adding Style

**Lesson:** [Lesson 6 — Styling Text with CSS](../README.md)
**Type:** Exploration
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/6/levels/2

## Instructions

This project is using a new language to add style to the page. With a partner, explore both the `index.html` and `style.css` files. Be ready to discuss the following questions:

- What changes is this new language making to the page?
- How is this language different from HTML?
- How are the `index.html` and `style.css` files connected?

*(Teacher note shown on this level: Have students explore this level with a partner. Afterward, lead a short share out so partners can share with the class their responses to the three questions above. The subsequent video should help reinforce what students discovered, so there's no need to lead a lengthy debrief conversation.)*
