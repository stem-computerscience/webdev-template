## Instructions

After we go through our first 3 steps of enabling flex, defining the flow direction, whether items should wrap or not, and defining how the items should be distributed horizontally, we have the option of defining how the items should be distributed in the container vertically. We can do this with the `align-items` property.

This property has 5 value options. Your job is to add the `align-items` property to each container and decide which of the five values to use for each container to make the page look like the example image provided on the level page.

### Do This
- Add the `align-items` property for each of the 5 div container rules in the stylesheet.
- Match the example image by applying the correct value with each of the `align-items` properties. Value options include:
  - `flex-start;`
  - `flex-end;`
  - `center;`
  - `baseline;`
  - `stretch;`
