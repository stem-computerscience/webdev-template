## Instructions

After we enable flex for container items, define the flow direction and whether items should wrap or not, the next step is to define how the items in the container should be distributed horizontally across the container. We will do this with the `justify-content` property.

This property has 6 value options. Assign each one to make the page look like the example image provided on the level page.

### Do This
- Add the `justify-content` property to each of the 6 div container rules in the stylesheet.
- Match the example image by applying the correct value with each of the `justify-content` properties. Value options include:
  - `flex-start;`
  - `flex-end;`
  - `center;`
  - `space-between;`
  - `space-around;`
  - `space-evenly;`

*Note: The exact spacing around and between the boxes may be slightly different depending on the size of your results window.*
