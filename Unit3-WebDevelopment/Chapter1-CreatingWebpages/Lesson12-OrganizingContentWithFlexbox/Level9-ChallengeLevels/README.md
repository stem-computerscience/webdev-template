# Level 9: Div and Flex (Challenge Levels)

**Lesson:** [Lesson 12 — Organizing Content with Flexbox](../README.md)
**Type:** Challenge
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/12/levels/9

## Instructions

Find an extra challenge or a new type of code here.

- **a — Flex-flow:** Learn how to use a shorthand property to set the direction and wrap in one line.
- **b — Gap spacing:** Learn a new property to control the spacing between rows and columns.
- **c — Child Selectors:** Learn how to style an element within a container differently than the rest!
- **d — Descendant Selectors:** Learn how to style the same type of elements within a container even if they aren't "direct children"!
- **e — Image Gallery Cards:** Learn how to create an image gallery with information underneath each image! *(Recommended — the gallery product cards built here come in handy for the Chapter 1 project.)*
- **f — Add to your Web Page!:** Use your new knowledge to add to the web page you started in a previous challenge level.
