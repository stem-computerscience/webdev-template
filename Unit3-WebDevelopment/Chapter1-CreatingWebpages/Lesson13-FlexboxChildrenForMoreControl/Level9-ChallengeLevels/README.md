# Level 9: Challenge Levels

**Lesson:** [Lesson 13 — Flexbox Children for More Control](../README.md)
**Type:** Challenge
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/13/levels/9

## Instructions

Expand your Flexbox skills with these challenges.

- **a — Flex-basis:** Learn about another Flex child property that determines the size of your item!
- **b — Flex Shorthand:** "Flex" your skills and learn how to combine `flex-grow`, `flex-shrink`, and `flex-basis` into shorthand!
- **c — Create a gallery:** Are you ready for the challenge of creating a gallery of images and text?
- **d — Add to your Web Page!:** Use your new knowledge to add to the web page you started in a previous challenge level.
