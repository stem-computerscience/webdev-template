# Level 6: Practice Levels

**Lesson:** [Lesson 13 — Flexbox Children for More Control](../README.md)
**Type:** Practice
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/13/levels/6

## Instructions

Try out what you've learned on one or more of the following activities.

- **a — Grow Based On Content:** Practice setting the `flex-grow` property based on if you want items to grow equally or not!
- **b — Step Layout:** Practice setting the `align-self` property to create some steps!
- **c — Ordered Steps:** Practice setting the `order` property to order the steps from practice level b!
- **d — Debug Me!:** Help Mya fix her code!
