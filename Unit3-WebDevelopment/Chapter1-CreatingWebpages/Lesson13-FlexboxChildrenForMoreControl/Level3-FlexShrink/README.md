## Instructions

The `flex-shrink` property sets the shrink factor for a flex item. This is used when items do not fit inside a container. Just like `flex-grow`, the `flex-shrink` property sets the shrinkage relative to other items.

The last item in the example has a `flex-shrink` of 4. This means it will shrink up to 4 times, or until the container is filled.

### Do This

**In the HTML file:**
- Give the 3rd child item a class attribute of `"shrink"`.

**In the CSS file:**
- Add a rule in the CSS file for the third child item using its class attribute as the selector.
- Give the third child item a `flex-shrink` property with a value of `4`.
- Resize the Preview Window to see the size change accordingly.
