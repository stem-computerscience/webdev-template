## Instructions

The `flex-grow` property specifies how much a flex item will grow relative to the rest of the flex items.

The last item stretches to fill the remaining space. Item 3 in the example has `flex-grow` set to 5, which means it will grow up to 5 times more than the other items, or until the container is filled.

### Do This

**In the HTML file:**
- Give the third child item a class attribute of `"grow"`.

**In the CSS file:**
- Add a rule in the CSS file for the third child item using its class attribute as the selector.
- Give the third child item a `flex-grow` property with a value of `5`.
- Resize the Preview Window to see the size change accordingly.
