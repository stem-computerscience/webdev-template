# Level 6: Uploading Images

**Lesson:** [Lesson 8 — Using Images](../README.md)
**Type:** Skill Building
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/8/levels/6

## Instructions

You can upload images that you've found elsewhere using the + button in the Files panel. Go find an image of a different type of pet that you like and download it to your computer (using right-click "Save As").

Once you have your images, click the upload button and upload the image from your computer into your project, where you can then use it in your page.

### Do This
- Find an image you are allowed to use and upload it to this project.
- Make sure the file name follows your naming rules.
- Use the `<img>` tag to display the image(s) in your website.
- Make sure to add an `alt` attribute!
- Add the attribution information below the image.
- (A "Show Me How to Upload" walkthrough is available if needed.)

### Recommended Search Engines
Because we can't know which sites might be blocked in your district, we've avoided pointing students to a specific search engine. Not all search engines make it easy to set Creative Commons filters — some of the easiest include:
- Creative Commons Search
- Google Image Advanced Search
- Wikimedia Commons
- Flickr Creative Commons

As with any site with crowdsourced content, search engine results will change from day to day, and some of those results may be inappropriate for the classroom. You may want to check these sites shortly before displaying them to the class, and decide what is best for your classroom.
