# Level 7: Adding Images (Practice)

**Lesson:** [Lesson 8 — Using Images](../README.md)
**Type:** Practice
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/8/levels/7

## Instructions

Practice your new skills here.

- **a — Image Bug Match**
- **b — Debug the missing image:** Use your debugging skills to figure out why the image is not appearing.
- **c — Debug the missing image 2:** Use your debugging skills to figure out why the alt text, but not the image, is appearing.
- **d — Debug the missing image 3:** Use your debugging skills to figure out why the image is not appearing.
- **e — Add alt to existing image:** Add alt attributes to describe existing images.
- **f — Add image link:** Add an image link to make the image appear in the web page.
- **g — Add new image:** Add an image to this recipe.

> Teaching note: Although this level can be used to assess student understanding of the syntax of the `<img>` tag, its main purpose is to make students aware of the most common types of bugs they may encounter when adding images to web pages.
