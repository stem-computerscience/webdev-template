# Level 9: All About You Reflection

**Lesson:** [Lesson 8 — Using Images](../README.md)
**Type:** Assessment
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/8/levels/9

## Instructions

Take a minute to reflect on the last level where you were tasked with adding images to a web page and answer the following questions:

- How do you think you did according to the Rubric below and why?
- How did you know how to complete this assessment?
- What was easy about the task? / What was the most challenging?
- What did you do to overcome the challenging part?
- What questions do you still have?

*(This is a free-response reflection level; a rubric is displayed on the page, and teachers can view student responses.)*
