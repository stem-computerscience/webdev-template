## Instructions

This page describes the four ghosts from Pac Man and Mrs. Pac Man, but only one of them is styled with a special class.

### Do This
- Look through the code to see how the "blinky" class works.
- Add a new class attribute in the `index.html` file for each of the other three ghosts.
- Add a class rule-set in the `style.css` file for each of the three ghosts.
- Add properties to each rule set to style the ghost's image and paragraph differently.
- (A "Show Me How" walkthrough is available if needed.)
