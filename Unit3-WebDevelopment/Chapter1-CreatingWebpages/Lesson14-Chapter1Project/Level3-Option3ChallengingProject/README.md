## Instructions

Demonstrate your skills and knowledge by building a webpage for a new user from start to finish! Complete each step, a through e, in order.

- **a — Step 1: Add User's Images:** Add your user's images to your project.
- **b — Step 2: Add User Content:** Next, add your user's content to the web page.
- **c — Step 3: Add Style:** Finally, add your user's style requests and layout to the page.
- **d — Step 4: Review The Page:** You're almost ready to publish your user's web page! Let's review it first!
- **e — Step 5: Publish The Page:** It's finished! Time to publish the page you made for your user!
