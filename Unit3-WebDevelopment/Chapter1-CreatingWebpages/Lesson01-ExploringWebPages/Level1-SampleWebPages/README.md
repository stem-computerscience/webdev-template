# Level 1: Sample Web Pages

**Lesson:** [Lesson 1 — Exploring Web Pages](../README.md)
**Source:** https://studio.code.org/courses/ai-discoveries-2026/units/3/lessons/1/levels/1

## Instructions

Look at each sample web page template and match it to the user it best suits.

| # | Template | Description |
|---|----------|-------------|
| a | Template A — "Photo Gallery!" | A photo gallery showing eight images taken by a local photographer. |
| b | Template B — "Dominic Lee Resume" | A resume for an aspiring web designer. |
| c | Template C | A catering website for a local caterer. |
| d | Template D | A website ranking the top five cutest dogs. |
| e | Template E | A website about visiting Tucson, Arizona. |

Students work in pairs to match each user description (from the *Web Design for Users* activity guide) to the template that best meets that user's needs, discussing their reasoning as they go.
