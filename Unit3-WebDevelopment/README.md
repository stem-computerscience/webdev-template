# Unit 3 — Web Development

Mirrored from Code.org's **AI Discoveries 2026** course, Unit 3: Web Development. Source: https://studio.code.org/courses/ai-discoveries-2026/units/3

In Web Development, students are put in the shoes of a web developer and empowered to design and create a web page to meet a user's needs. As students develop pages and begin to see themselves as web developers and designers, they are encouraged to think critically about the impact of sharing information online and how to be more critical consumers of content. They're also introduced to problem-solving related to programming while learning valuable skills such as debugging, using resources, and teamwork. At the conclusion of Chapter 1, students design and create a web page for a user. After Chapter 2, students will have worked with a team to create a multi-page website they can publish and share.

Each lesson folder contains a `README.md` with the full lesson plan (overview, objectives, standards, teaching guide, and resource links) plus one subfolder per level containing that level's instructions. Google Slides/Docs resources are linked from each lesson's Resources section; native `.pptx`/`.pdf` copies are added to these folders separately once available.
