# Post-Project Test — Web Development

A locked, single-page assessment covering Unit 3 content (referenced internally by Code.org as "Unit 2" lesson numbers — this is Code.org's internal course numbering and does not match the Unit 3 lesson numbers used in this repo). Some questions include image-based answer choices that could not be captured as text; those are noted below.

## Questions

1. **Which word is best defined as "a language used to describe how HTML elements should be styled"?**
   A. HTML  B. CSS  C. Tag  D. Heading  E. Element
   **Answer: B. CSS**

2. **Which of these tasks are most appropriate for CSS?** *(Select all that apply)*
   A. Change the background color  B. Add an image  C. Add a link  D. Change the font size  E. Add text
   **Answer: A, D** — CSS is used to style a web page; changing background color and font size are style changes. HTML is used to add content such as images, links, and text.

3. **Which are you more likely to find in a CSS file?** *(Select all that apply — answer choices are images of code snippets, not captured as text)*
   **Answer: A, C** — In CSS files, rules are found inside curly braces `{}` and each rule consists of a property name and a value, separated by a colon `:`. HTML tags use `<>`.

4. **Given a website with a "clouds and rainbows" image class, what would you add to the CSS file so those images have a height of 50px?** *(answer choices are images, not captured as text)*
   **Answer: B** — Both images share the class `weather`. To write a rule-set for a class selector, prefix the selector with a `.` before the class name.

5. **Given a webpage, predict the HTML.** *(answer choices are images, not captured as text)*
   **Answer: A** — Headings are section titles of different sizes, marked by the number next to the `h` in the heading tag, from `<h1>` to `<h6>`.

6. **Debug the following image tag:** `<img src=rainbow.jpg" alt="a rainbow">`
   A. There should not be an alt attribute
   B. `img` should be `image`
   C. Add a starting quotation mark to the name of the rainbow.jpg file
   D. Add a closing `</img>` tag
   E. No change is necessary
   **Answer: C**

7. **Given a webpage and its HTML, predict the CSS.** *(answer choices are images, not captured as text)*
   **Answer: C** — `<h1>` renders smaller than `<p>` (normally the reverse), implying CSS rules change the font-size of one or both tags; `<p>` is also colored blue.

8. **Which of the following is an example of your digital footprint?**
   A. Your birthday  B. Your address  C. Your phone number  D. Your name  E. All of the above
   **Answer: E. All of the above**

9. **Which of the following elements most likely increases a website's trustworthiness?**
   A. Posted anonymously  B. Images are high quality  C. Lots of ads  D. Sources are cited
   **Answer: D. Sources are cited**

10. **When `flex-wrap` is set to `wrap` and `flex-direction` is `column`, how will flex items behave in a container that exceeds its height?**
    A. Items will wrap from top to bottom
    B. Items will overflow the container without wrapping
    C. Items will align vertically until reaching the container's maximum width
    D. Items will wrap onto a new column beside the first
    **Answer: D** — `flex-wrap: wrap` causes items to wrap onto a new column when they exceed the container's height.

11. **What Flex properties have been applied to create the pictured layout?** *(image not captured as text)*
    A. `align-items: space-between;` and `justify-content: center;`
    B. `justify-content: space-between;` and `align-items: center;`
    C. `justify-content: space-around;` and `align-items: flex-start;`
    D. `align-items: space-evenly;` and `justify-content: center;`
    E. `justify-content: center;` and `align-items: center;`
    **Answer: B**

12. **In a flex container with `align-items: flex-start`, one child item has `align-self: flex-end`. What impact does `align-self` have on this item?**
    A. It has no effect since `align-items` is set to `flex-start`.
    B. It overrides `align-items`, aligning the item at the end of the container.
    C. It makes the item align in the center of the container.
    D. It causes the item to grow to fill the container.
    **Answer: B**

13. **Match the CSS property to its definition:** `color`, `font-size`, `float`
    - `color` → specifies the color of text
    - `font-size` → specifies the size of a font
    - `float` → places an element on the left or right side of the screen and allows text and other elements to wrap around it

14. **What is the purpose of copyright?** *(free response)*
    Copyright is intended to protect the rights of content creators. These rights include being recognized as the creator when the work is displayed, or deciding who can use and make money from the work.
